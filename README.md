## Requisitos

- NodeJS 22+

## Configuração

- Configurar URL base da API em um `.env` (seguir `.env.example`)
- Instalar bibliotecas (`npm i`)
- Rodar o projeto em modo desenvolvimento (`npm run dev`)
- Acessar no navegador, em `http://localhost:5173`

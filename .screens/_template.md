# Nome da Tela

## Objetivo

Descrever em uma frase o valor da tela para o fluxo do GCEI.

## Referência no TAP

- RF:
- RNF:

## Rota Sugerida

- Exemplo: `/login`

## Perfil de Acesso

- Público
- Egresso autenticado

## Conteúdo Obrigatório

- Título da tela
- Texto de apoio
- Blocos de dados
- Ações primárias e secundárias

## Componentes `shadcn` Preferenciais

- Listar primeiro os componentes já existentes.
- Se faltar algum, registrar o nome do componente `shadcn` que deve ser adicionado.
- Evitar markup customizado para elementos que já existam no ecossistema.

## Estrutura da Interface

- Cabeçalho
- Corpo
- Rodapé
- Navegação

## Estados Necessários

- Carregando
- Vazio
- Erro
- Sucesso
- Bloqueio, quando aplicável

## Regras de Negócio Visíveis

- O que o usuário pode fazer
- O que o usuário não pode ver ou editar

## Checklist de Planejamento

- Rótulos visíveis em todos os campos
- Foco visível
- Botões com texto específico
- Conteúdo preparado para telas pequenas
- Sem gradiente
- Sem expor dados sensíveis
- Sem inventar componente quando houver componente do `shadcn` que já serve

## Observações

- Decisões abertas
- Dependências com outras telas
